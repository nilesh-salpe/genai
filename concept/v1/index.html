Seven parts · forty-two live derivations

Neural networks and transformers, built from scratch

A course in seven parts. The zeroth builds the plain maths underneath everything else — functions, derivatives, expected value — with no machine learning in sight; the first derives every neural-network and transformer formula from the problem it solves; the second assembles them into a working digit classifier; the third builds four more models from that same toolkit, easiest first, and trains them in front of you. The fourth swaps hand-written backward passes for PyTorch's autograd; the fifth fills in the architecture the first part left out — encoder vs. decoder, cross-attention, decoding; the sixth wires all of it into a small GPT you train and sample from yourself. Nothing is asserted before it is motivated.

Who this is for

Anyone comfortable adding, multiplying, and dividing — nothing more. Part zero builds function notation, vectors and matrices, exponentials and logarithms, derivatives, and expected value and variance, all from scratch and with no neural network in sight; part one puts every one of those tools to work. No machine learning background assumed anywhere.

What the widgets are for

Change an input and watch the stated consequence happen, for example:

  • Add 100 to every logit and watch softmax not move — shift-invariance, and why real code subtracts the max
  • Test three candidate loss functions against "independent surprises add" — only −log p survives, at every setting
  • Turn off the ÷√dk and watch attention's gradient collapse
  • Set all weights to zero and watch a network fail to move at all
  • Shuffle an image's pixels and see why a dense layer does not care

Running it

Every page is a single self-contained HTML file — no build step, no dependencies, no network calls beyond the web font. Open any file directly in a browser, or serve the folder with python3 -m http.server. Part three's Python files need only NumPy (and scikit-learn, for one bundled dataset) — run any of them directly: python3 examples/01_mlp_spiral_classifier.py. Part six's is the one exception that needs PyTorch: pip install torch && python3 examples/05_tiny_gpt.py.

Reduced-motion preferences are respected throughout; every animation degrades to its final state.

A personal footnote: not the author's first pass at a weighted-matrix model. A 2007 blog post proposed predicting human behaviour with a matrix of pairwise influence weights, explicitly likened to neural-network weights — the same shape of object attention uses, though without attention's defining move: those weights were symmetric and fixed, not computed per-query from content. A precursor in form, not in mechanism.
