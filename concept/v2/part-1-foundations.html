The plain maths, before any network

Ten small tools, built from nothing but arithmetic: functions, sums, vectors, matrices, exponentials, derivatives, the chain rule, the gradient, and probability. No neural network appears anywhere on this page — Part 2 puts every one of these to work. If a tool below is already familiar, skim it; the goal is that nothing in Part 2 ever uses a symbol this page didn't first build.

01Machines with slots

A function is an input, a rule, and an output

f(x) = 2x + 1 is a machine: feed it 3, it applies "double, then add one," and hands back 7. The letter x is a placeholder — it's not a number until something is fed into the slot. Functions can take more than one input (f(x,y) = x·y is a two-slot machine), and the output of one can feed straight into another: f(g(x)) means run x through g first, then feed that result into f. A neural network, eventually, is nothing but this — functions feeding functions, many layers deep.

02Adding many things

Σ is a loop, not a new idea

Σᵢ xᵢ means "add up every xᵢ, one after another." If x = [4, 1, 3], then Σᵢ xᵢ = 4+1+3 = 8. A rule is often attached: Σᵢ xᵢ² means square each one first, then add — 16+1+9 = 26. Every dot product, every layer, every loss function in this course is a Σ wearing a costume: a rule applied to many things, then totalled into one number.

03Bundles of numbers

A vector is a list — and a point

Computers only do arithmetic, so anything a network reasons about — a photo, a word, a house — first becomes a list of numbers. [34, 52000, 8] could be age, income, years of schooling: a filled-in form. It's also, simultaneously, a point with three coordinates. That second reading is what lets geometric questions — "how far apart," "how aligned" — get asked about things that aren't obviously geometric at all.

04The core operation

The dot product measures agreement

w · x = Σᵢ wᵢxᵢ — multiply matching entries, add the results. Multiplying, not adding, is what makes it measure agreement: care a lot (wᵢ large) but the feature is absent (xᵢ = 0)? Contributes nothing. Both large and the same sign? Contributes a lot. One number, summarising "how much do these two lists point the same way."

05Doing it in bulk

A matrix is many dot products, asked at once

Stack several "what I care about" vectors as rows of a grid, and one multiplication asks every question simultaneously: (Wx)ᵢ = Σⱼ Wᵢⱼxⱼ — row i of W, dotted with x. It's bookkeeping, not new machinery.

Worked example. Let W be 2×3 and x be a 3-vector:

W = [[1, 0, 2], [−1, 3, 1]]    x = [2, 1, 0]

Row 1 dotted with x: 1×2 + 0×1 + 2×0 = 2. Row 2: −1×2 + 3×1 + 1×0 = 1. So Wx = [2, 1] — a 2×3 matrix times a 3-vector gives a 2-vector, exactly as many outputs as rows.

The shape rule derives itself. Every output entry needs a row from the first matrix and a column from the second, and a dot product needs both the same length — so inner dimensions must match, and you get one output per (row, column) pair: (m×n)(n×p) = (m×p), nothing to memorise.

The constant term. y = mx + c needed +c so an input of zero isn't forced to output zero. The matrix version needs the same fix: Wx + b, a constant vector added after the multiply.

Exponentials and logarithms

eˣ answers "what does multiplying e by itself this many times give?" — fractional and negative exponents fill in the curve smoothly (e⁰·⁵ ≈ 1.65, e⁻¹ ≈ 0.37). log x asks the reverse: "e to what power gives this number?" They undo each other, the same way squaring and square-rooting do.

07Rates of change

The derivative: how steep, right here

f(x) = x² barely moves near x=0 and rockets upward near x=10 — "the derivative" names the steepness at one exact point. Pick two nearby points, draw the line through them (a secant), and shrink the gap toward zero: the secant settles onto the tangent, and its slope is f′(x).

The chain rule: rates feeding rates

h(x) = (2x+1)² is an inner function g(x)=2x+1 feeding an outer one f(u)=u². Nudge x; that nudges g by rate g′(x); that nudge in g then nudges f by a further rate f′(g(x)). Two rates back to back multiply:

d/dx f(g(x)) = f′(g(x)) · g′(x)

This is not a trick — it's bookkeeping for "one rate feeding into another" — and it is the entire idea behind backpropagation, just with thousands of layers of nesting instead of two.

09Many inputs at once

The gradient: one derivative per input

A loss function takes millions of inputs — one per weight. Freeze every input but one and take the ordinary derivative of just that one: a partial derivative, ∂f/∂x. Collect one partial derivative per input, in order, and you have the gradient — a vector where entry i answers "nudge only input i — how fast does the output move?"

Training a network with millions of weights changes nothing about this picture — it just collects millions of partial derivatives into one gradient instead of two, and moves every weight a small step opposite it.

10Randomness

Probability, conditional probability, and the average of "it depends"

What a probability is. An outcome is one thing that could happen; the sample space is the full list of possibilities. A probability P(event) is a number between 0 and 1 saying how likely that event is, and across every outcome in the sample space, the probabilities add up to exactly 1 — that full list of (outcome, probability) pairs is called a probability distribution. Roll a fair die: six outcomes, each P = 1/6, summing to 1.

Conditional probability: does new information change the odds?

P(A | B) reads "the probability of A, given that B already happened" — restrict attention to only the cases where B is true, then ask how often A is also true inside that narrower world. Independence is the special case where B tells you nothing: P(A|B) = P(A), knowing B changes nothing about A.

Careful: P(A|B) is not P(B|A). "Given it's raining, the ground is wet" is nearly certain; "given the ground is wet, it's raining" isn't — a sprinkler could have done it. Mixing the two up is the single most common probability mistake.

Expected value and spread

E[X] = Σᵢ pᵢxᵢ — multiply each outcome by its probability and add: a probability-weighted average, the long-run balance point. Variance, E[(X−E[X])²], is the expected squared distance from that balance point; its square root is the standard deviation, the typical size of a deviation.

One fact worth holding onto: for independent quantities, variances add — so summing n independent unit-variance things gives spread √n, not n, because the random signs partially cancel. Part 4 uses exactly this to explain why attention needs a √d_k scaling factor.

11Onward

What Part 2 assumes from here

A function as an input/output machine, Σ as an addition loop, vectors and matrices as bundles of numbers with a well-defined way to multiply, exp/log undoing each other, the derivative and chain rule computed without ever taking a limit by hand, the gradient as one partial derivative per input, and probability — including the conditional kind — as the language for "how sure, and does new information change that." Nothing in Part 2 is new machinery; it's these ten tools, pointed at a network for the first time.
