Who this is for

Anyone with school algebra and a first calculus course, and no machine learning background. Linear algebra and the two required probability facts are built from scratch inside part one.

What the widgets are for

Each one exists to make an argument checkable rather than to decorate the page:

  • Add 100 to every logit and watch softmax not move — shift-invariance, and why real code subtracts the max
  • Test three candidate loss functions against "independent surprises add" — only −log p survives, at every setting
  • Turn off the ÷√dk and watch attention's gradient collapse
  • Set all weights to zero and watch a network fail to move at all
  • Shuffle an image's pixels and see why a dense layer does not care

Running it

Both pages are single self-contained HTML files — no build step, no dependencies, no network calls beyond the web font. Open either file directly in a browser, or serve the folder with python3 -m http.server.

Reduced-motion preferences are respected throughout; every animation degrades to its final state.
